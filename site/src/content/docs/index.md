runnerd runs ephemeral GitHub Actions runners on a Linux host: one fresh container per job, from one pool shared by the repositories you configure, kept inside a memory and CPU budget.

It is in early development. Today it only reads and checks its config; it does not start runners yet. Install instructions and a guide will appear here once there is something to install.

The source and current status are on [GitHub](https://github.com/ayagmar/runnerd).
